项目简介

🎯

解决什么问题

文献调研需要在 arXiv、Semantic Scholar、Crossref 等多个数据库间来回切换、逐库搜索、手动整理。LitScan 用一条命令 / 一个页面完成多库并行检索，结果统一为标准化 CSV。

⚙️

核心价值

三入口共用一套核心：CLI 脚本化批量跑、Web 页面所见即所得（SSE 流式进度）、REST API 供上层系统调用。零数据库依赖，纯文件输出，开箱即用。

🆚

与同类工具的差异

不依赖浏览器自动化、无需 API Key 即可使用大部分数据源；内置 429 限流自动退避重试与代理管理（配置文件 / 环境变量 / --no-proxy 三级控制）；检索历史可一键重跑。

架构全景

三层结构：接入层统一入口 → 核心层调度与抓取 → 输出层落盘。hover 节点查看说明。

核心机制

🔁

智能重试与限流退避

429 触发线性退避（retry_delay × attempt），5xx 逐次重试，最多 max_retries: 4 次。限流/重试事件通过回调上抛，CLI 与 SSE 各自渲染进度。

🛡️

代理三级控制

显式配置 request.proxy → 自动读取环境变量 http_proxy/https_proxy → --no-proxy 强制直连。学术论文流量可按 Rule 模式绕开代理。

🕘

可重放的检索历史

每次检索落盘为 JSON 记录（关键词/源/年份/条数/各源命中），Web 一键重跑、CLI --retry <ID>、API POST /api/history/retry/{id} 三端复用。

core/fetcher.py — 429 限流退避（节选）
1if resp.status_code == 429:
2    wait_time = retry_delay * attempt
3    info = RateLimitInfo(source_name, wait_time, attempt, max_retries)
4    if on_rate_limit:
5        on_rate_limit(info)
6    time.sleep(wait_time)
7    continue

快速开始

1 · 安装依赖
pip install -r requirements.txt
2 · 启动 Web 服务（推荐）
python litscan.py --serve     # 打开浏览器访问 http://127.0.0.1:8000
3 · CLI 检索
python litscan.py                          # 用 config.yaml
python litscan.py -k "my research topic"   # 命令行指定关键词
python litscan.py -k "LLM agent" -y 2023 -l 20
python litscan.py --retry 20260909_123456  # 从历史记录重新检索
python litscan.py --no-proxy               # 强制不走代理
config.yaml — 关键配置
query:
  keywords: "LLM agent evaluation benchmark"
  year_from: 2022
  limit_per_source: 30

request:
  timeout: 45
  max_retries: 4
  retry_delay: 8
  proxy: null  # null=自动读环境变量; "none"=不走代理

history:
  enabled: true
  max_records: 200

API 接口

16 个 REST 端点，启动服务后访问 http://127.0.0.1:8000/docs 查看交互式文档（Swagger UI）。

方法路径说明
GET/api/sources列出检索源
POST/api/search多库检索
GET/api/search/streamSSE 流式检索（实时进度）
POST/api/search/{source}单库检索
GET/api/articles最近一次结果
GET/api/stats运行统计
GET/api/history搜索历史
GET/api/history/stats历史统计
GET/api/history/{id}单条历史详情
POST/api/history/search搜索历史记录
POST/api/history/retry/{id}从历史重新检索
DELETE/api/history/{id}删除历史记录
DELETE/api/history清空历史
GET/api/logs操作日志
GET/api/logs/stats日志统计
DELETE/api/logs清空日志
调用示例
curl -X POST http://127.0.0.1:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{"keywords": "LLM agent evaluation", "limit_per_source": 10}'
